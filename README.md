## *2.What is DOCTYPE in Html ?*
<!DOCTYPE> is a document type declaration that tells web browsers how to interpret and render a web page correctly. It is not an HTML tag, but rather an instruction that must be placed at the absolute top of your HTML document, before the <html> tag.

## *3.What is Void Element and Example for Void Elements ?*
Void elements in HTML are elements that cannot have any child nodes (no nested elements and no text). They consist of only a start tag; defining an end tag for them is completely invalid in HTML.
Ex : `<img> <br> <hr>`

## *4.What is Different Element and Attributes ?*
An HTML element is the complete, functional unit of a webpage made up of an opening tag, content, and a closing tag (e.g.,` <p>Hello World</p>`), whereas an HTML attribute is a modifier placed inside the opening tag that provides extra information or changes the behavior of that element (e.g.,` class="center" or href="..."`)

## *5.What is Html Entries and Why is it need in HTML ?*
HTML entities are special sequences of text used to display reserved characters, invisible characters, and symbols that cannot be easily typed or read by a web browser. They typically begin with an ampersand (&) and end with a semicolon (;).
For example, the HTML entity &lt; displays as the less-than sign (<), and &copy; displays the copyright symbol (©)

##  *6.What are meta tag and why is it used *
An HTML <meta> tag provides metadata about a webpage, which means it supplies "data about data". Placed exclusively inside the <head> section of an HTML document, these tags do not appear directly on the website for visitors to see. Instead, they work behind the scenes to supply critical instructions to search engines, web browsers, and social media platforms regarding how to understand, index, and render the webpage.
